# Palautog AI - Mobile Running Guide

## Option A: Using Layla App (Android/iOS)
1. Download the 'Layla' app from the Play Store or App Store.
2. In the app, download any Qwen 2.5 1.5B GGUF model (Q4_K_M is recommended for low-end devices).
3. Go to the Character Creator in Layla and paste the system prompt found in 'palautog_profile.json'.

## Option B: Using Termux (Advanced Android)
1. Install Termux and setup python.
2. Install 'llama.cpp' or compile it on your device.
3. Run the model locally in your terminal!
